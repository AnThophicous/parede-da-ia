(01)

Manifesto

Agentes de IA escrevem front-end como quem nunca abriu um site premiado. Eles não veem o que constroem, não sentem o scroll, não medem o contraste. A parede-da-ia dá a eles olhos, mãos e repertório — e proíbe declarar pronto o que não foi visto.

(02)Arquitetura

Um router.
Zero prompt monolítico.

O agente lê só o router.md, classifica a sua intenção e busca sob demanda apenas os módulos necessários. Contexto é orçamento — e cada token carregado precisa merecer o lugar.

(04)Toolkit

Olhos e mãos.

Um daemon Playwright mantém um Chromium vivo entre chamadas. O agente abre, rola, clica, grava e mede — de verdade, com eventos reais de wheel e mouse.

  • web-url-fetch abre e injeta hooks
  • web-wait-page-load load + networkidle + fontes
  • web-wait fallback para pre-loaders WebGL
  • web-screenshot alta definição, full-page, mobile

(05)Protocolo frontend-master

Perguntar antes.
Ver depois.

Fase 1 — Elicitação obrigatória

Nenhuma linha de código antes de entender.

  1. 01Qual é o objetivo central e o ápice visual esperado?
  2. 02Os assets vêm do código (SVG/WebGL), de você ou de uma referência?
  3. 03Você tem referências — ou pesquiso no Awwwards e proponho 2–3 direções?
  4. 04Stack, marca, prazo, performance e acessibilidade obrigatórias?

Fase 2 — Loop autônomo de QA visual

Sobe o servidor, abre, clica em tudo, grava, mede, corrige.

(06)Instalação

Um prompt.
Seu agente faz o resto.

Clique para copiar o prompt de bootstrap universal. Cole no Claude Code, Codex, OpenCode, Cursor ou Windsurf: o agente lê o doc.md do repositório, instala Playwright, verifica o FFmpeg e registra o router nas próprias instruções globais.
