# Template · direção criativa

> Use para cada uma das 2–3 direções. Mesma estrutura em todas, para o usuário comparar lado a lado.

```markdown
### Direção <A|B|C> — <Nome curto e memorável>

**Conceito:** <uma frase — a ideia, não a técnica>
**Família:** <id da estética> (+ <secundária>) · playbook: `aesthetics/<id>.md`
**Para quem funciona:** <por que combina com as respostas do usuário>

**Referências**
- <url/vídeo> → extrair: <princípio, medida ou sistema>
- <url/vídeo> → extrair: <…>

**Tokens iniciais**
- Tipografia: <display> / <texto> / <mono> — eixos variáveis: <wght 100–900…>
- Paleta: <fundo> · <texto> · <acento 1> · <acento 2> — razão de contraste do texto principal: <x:1>
- Forma: raio <…> · sombra <…> · textura <grão/ruído/nenhuma>
- Movimento: rápido <ms> · base <ms> · lento <ms> · curvas <…>

**Ápice visual:** <onde, como entra, como sai, em quanto tempo>
**Assinatura de movimento:**
1. <microinteração> — gatilho → feedback
2. <transição de seção>
3. <efeito de tipo/cursor>

**Stack e assets:** <Paper Shaders / Three.js / GSAP / Lenis / CSS puro> · assets: <código | usuário | IA | placeholders>
**Riscos:** <performance, acessibilidade, produção> → mitigação: <…>
**Custo relativo:** baixo | médio | alto
```

Fechamento obrigatório: **"Recomendo a direção X porque …"** + pergunta direta pedindo a escolha.
