# Template · creative direction

> Use it for each of the 2–3 directions. Same structure in all of them, so the user can compare side by side.

```markdown
### Direction <A|B|C> — <Short, memorable name>

**Concept:** <one sentence — the idea, not the technique>
**Family:** <aesthetic id> (+ <secondary>) · playbook: `aesthetics/<id>.md`
**Who it works for:** <why it fits the user's answers>

**References**
- <url/video> → take: <principle, measurement or system>
- <url/video> → take: <…>

**Initial tokens**
- Typography: <display> / <text> / <mono> — variable axes: <wght 100–900…>
- Palette: <background> · <text> · <accent 1> · <accent 2> — main text contrast ratio: <x:1>
- Form: radius <…> · shadow <…> · texture <grain/noise/none>
- Motion: fast <ms> · base <ms> · slow <ms> · easings <…>

**Visual climax:** <where, how it comes in, how it leaves, how long>
**Motion signature:**
1. <microinteraction> — trigger → feedback
2. <section transition>
3. <type/cursor effect>

**Stack and assets:** <Paper Shaders / Three.js / GSAP / Lenis / plain CSS> · assets: <code | user | AI | placeholders>
**Risks:** <performance, accessibility, production> → mitigation: <…>
**Relative cost:** low | medium | high
```

Mandatory close: **"I recommend direction X because …"** + a direct question asking for the choice.
